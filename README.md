Xtal signal generator, for RF conversion to a 7 MHz RX. The oscillator uses a SI5351 module and allows both the setting of 10 i plus bands, and also the shift with respect to the selected bands of +/- 500 kHz.
The amplification of the RF generator signal (of about 3-4 dBm) and any filtering are delegated to subsequent stages.
The software is made for an Arduino UNO board, but it works fine with any Arduino board you have.
